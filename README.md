# Nutrition-App-Project
Repo for my nutrition app project

Plan:
- I am going to develop a nutrition tracking app (not a particularly revolutionary idea, but I just want to), usable on both iOS and Windows so that I can use it on my phone and pc.
- My reason for doing so is that my current way of tracking nutrition is just myself and a calculator, which makes tracking across multiple days virtually impossible and reliability of the numbers inaccurate.
- Another benefit of having an app to track this would be something like a streak/milestone feature common in other apps e.g. Duolingo which appeals greatly to my somewhat addictive personality, which would also help me to maintain my nutrition goals.
